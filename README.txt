HADI.DEV — CINEMATIC PORTFOLIO

CARA MENJALANKAN
1. Extract folder portfolio-scroll-animation.
2. Pastikan index.html, styles.css, app.js, dan file gambar tetap berada dalam satu folder.
3. Buka index.html di browser.

PENAMBAHAN VERSI INI
- Cinematic project case study modal untuk ketiga proyek.
- Tech stack logo rail dengan efek hover.
- Learning journey / education timeline.
- Interactive project screenshot preview saat hover/focus.
- Tautan navigasi Journey pada desktop, mobile, dan footer.

CATATAN
Desain utama, foto, isi profil, proyek, kontak, media sosial, footer, dan fungsi yang sudah ada tetap dipertahankan. Internet diperlukan untuk memuat Tailwind CDN, Google Fonts, dan Lucide Icons.
